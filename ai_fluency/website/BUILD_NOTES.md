# Portfolio build notes

## Design direction

- **Audience:** hiring managers and peers who want to see how the work was built.
- **Single job:** let a visitor understand the case study, try one small feature, and inspect the evidence.
- **Palette:** ink `#18231c`, paper `#f4f0e7`, lilac `#d7c8ff`, signal yellow `#f6c85f`, moss `#a8c6a5`, coral `#f28b6b`.
- **Type:** Georgia for the thesis/headlines, Arial for body copy and interface controls, monospace for evidence labels.
- **Signature:** an amber “evidence ribbon” that follows each case card from question to measured result to next check.

## Wireframe

```text
[nav]                         [paper / repo]
[thesis + live status] [large evidence ribbon]
[three proof blocks]
[interactive case explorer + agent preview]
[workflow + QA notes]
[footer with badge status]
```

The page avoids stock dashboard styling: the layout reads like a research notebook with a movable evidence ribbon, strong typographic thesis, and quiet controls.
